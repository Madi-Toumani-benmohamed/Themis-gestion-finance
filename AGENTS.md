# Instructions des agents — Thémis

## Contexte
Thémis est une application de gestion financière personnelle.

Avant toute modification importante, consulter :
- CODEBASE_GRAPH.md

## Principes
- Préserver la confidentialité des données bancaires.
- Respecter l'architecture existante.
- Privilégier les modifications ciblées.
- Ne pas inventer de données financières.
- Ne pas confondre période incomplète et bilan définitif.
- Vérifier les impacts sur les autres composants.

## Développement
- Examiner les fichiers concernés avant modification.
- Respecter les conventions existantes.
- Ajouter des tests pour les corrections fonctionnelles.
- Ne pas écraser les changements non commités.

## Validation
- Exécuter les tests pertinents.
- Vérifier le build.
- Présenter les modifications et les résultats.
